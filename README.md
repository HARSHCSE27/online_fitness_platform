# FitLife - Online Fitness Platform

A beginner-friendly web application built with Python and Streamlit.

## Features
- Dashboard
- Workout plans
- Exercise library with search/filter
- Progress tracking and chart
- BMI calculator
- Daily calorie estimate
- User profile and weekly goals
- Responsive modern UI

## Run the application

1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Start the app:

```bash
streamlit run app.py
```

5. Open the local URL shown in the terminal, usually:
http://localhost:8501
